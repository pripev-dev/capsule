# The synthetic golden

An invented recipe, an invented speaker, and what the Claude Design composer made
of them. **Nothing here is a family's.** That is the point: this repository goes
public, and a fidelity test that needs private material is a test a clean clone
cannot run.

## Where the expectations come from

`expected-capsule.json`, `expected-surfaces.json` and `expected-run.json` were
produced by the **archived prototype** – the Stage 1 export of Claude Design
project `67e3d299-545a-443b-a187-0ec05e95ecb0`, loaded through plain `require`,
which those files support unmodified. They were not produced by the code in
`src/engine/`.

That distinction is the whole value of the fixture. An expectation generated by
the thing under test proves only that it agrees with itself. These bytes came
from the composer as it stood before the port, so `test/public-golden.test.mjs`
comparing against them is a real check that the IIFE → ESM conversion moved
nothing.

**If that test fails, the port is wrong.** Never regenerate the expectation to
match the output.

## Three things this fixture pins on purpose

**The title is `"The"`.** English ships question wording and player chrome but no
lexicon, so `structuring-spoken-recipes` runs on `lexicon.default.json` –
structure with no vocabulary. Nothing is broken; the pack is honest about what it
lost. Writing an English lexicon should visibly change this line, which is why it
is asserted rather than tidied.

**The capsule's locale is `"und"`, though `"en"` was declared and detected.** A
locale is only claimed when a lexicon backs it. Undetermined is the truthful
answer here.

**The composed document is not a contract-valid capsule.** It satisfies no
version of `schemas/capsule.schema.json`: it is a page composition – blocks,
claims, fonts, compositions – and the contract additionally requires consent,
people, recordings, preservation, access, version and migration. Every prototype
output has this gap, the four archived runs and both cold starts included. It is
not the engine's to close – geometry is this package's job and assembling a
contract-complete capsule is the cookbook agent's – so the test asserts the gap
and lists it. When Phase D closes it, that test fails, and it should.
